## 1. 设计概述

### 1.1 功能

每台从机通过 PCB 叉指电极探头 + TLC555 非稳态振荡器测量土壤电容（湿度），利用 STC8G1K17A 的 Timer0 硬件脉冲计数，在主机发起通信时通过 4 芯总线回传 16-bit 脉冲数 + CRC-8。

### 1.2 系统位置

```
                        4芯总线 (VCC, GND, CLK, DATA)
    ┌─────────┐         ───┬──────────────┬──
    │ ESP32   │            │              │
    │ (主机)  │────────────┼──────────────┼────── 从机 0..15
    └─────────┘            │              │
                      ┌────┴────┐    ┌────┴────┐
                      │ 从机 #0 │    │ 从机 #1 │  ...
                      │ STC8 +  │    │ STC8 +  │
                      │ TLC555  │    │ TLC555  │
                      │ + 探头  │    │ + 探头  │
                      └─────────┘    └─────────┘
```

### 1.3 关键参数

| 参数 | 值 |
|------|-----|
| MCU | STC8G1K17A, SOP-8 封装 |
| 振荡器 | TLC555 (CMOS 版 NE555), 非稳态模式 |
| 探头类型 | PCB 叉指电极 (绝缘层 + 防水漆) |
| 测量原理 | 土壤作介电质 → 电容变化 → TLC555 频率变化 → Timer0 硬件计数 |
| 并联基准电容 | 100pF NP0/C0G |
| 测量窗口 | 10ms (50 CLK @ 5kHz) |
| 频率范围 | ~63kHz (湿) ~ ~184kHz (干) |
| 每从机 BOM | 12 种 / 13 颗元件 |

## 2. 引脚分配

### 2.1 STC8G1K17A SOP-8 引脚映射

```
         ┌─────┐
T0/P5.4 ←│1   8├→ P3.3/INT1/DATA (→ 总线 DATA, 经 220Ω)
  VCC   ←│2   7├→ P3.2/INT0/CLK  (← 总线 CLK,  经 100Ω)
LED/P5.5→│3   6├→ P3.1/TxD       (悬空)
  GND   ←│4   5├→ P3.0/RxD/INT4  (悬空, 弱上拉)
         └─────┘
```

### 2.2 引脚功能表

| PIN | 丝印 | 功能 | 方向 | 配置 | 连接 |
|:---:|------|------|:---:|------|------|
| 1 | P5.4/T0 | TLC555 脉冲计数 | 输入 | 高阻, Timer0 外部计数 | TLC555 pin3 (OUT) |
| 2 | VCC | 5V 供电 | — | — | 总线 VCC, 100nF+47μF 去耦 |
| 3 | P5.5/T1 | 状态 LED | 输出 | 推挽 | 1kΩ + LED → GND |
| 4 | GND | 地 | — | — | 总线 GND |
| 5 | P3.0/RxD | (悬空) | — | 弱上拉 | NC |
| 6 | P3.1/TxD | (悬空) | — | 高阻 | NC |
| 7 | P3.2/INT0 | CLK 输入 | 输入 | 高阻, 边沿中断 | 总线 CLK (经 100Ω 串联) |
| 8 | P3.3/INT1 | DATA 双向 | 双向 | 开漏 / 高阻 (分时) | 总线 DATA (经 220Ω 串联) |

### 2.3 引脚决策详解

#### 2.3.1 T0 在 P5.4 (PIN1)

SOP-8 封装的 STC8G1K17A 将 Timer0 外部输入映射到 P5.4，而非 SOP-16 封装的 P3.4。

| 注意事项 | 说明 |
|------|------|
| RST 复用 | P5.4 默认同时是外部复位脚 (RST)。需在固件初始化时写 `RSTCFG` 寄存器关闭外部复位功能，将其配置为纯 GPIO/T0。 |
| ISP 烧录 | 冷启动上电时仍可通过 ISP 进入烧录模式，不受影响。 |
| 烧录方式 | 使用 SOP-8 烧录夹，P3.0/P3.1 不引出做调试串口。 |

#### 2.3.2 CLK/DATA 对应 INT0/INT1

P3.2 (INT0) 和 P3.3 (INT1) 天然匹配通信协议的 CLK/DATA 需求：

| 引脚 | 中断源 | 用途 | 固件细节 |
|------|:---:|------|------|
| P3.2 | INT0 | CLK 边沿检测 | 测量阶段上升沿中断计数; 传输阶段上升沿/下降沿均可触发以递增槽位 |
| P3.3 | INT1 | DATA START 检测 + 数据传输 | 空闲态下降沿中断检测 START 条件; 传输阶段切换为开漏输出 |

#### 2.3.3 P5.5 驱动 LED

| 参数 | 值 |
|------|------|
| LED 颜色 | 红色或绿色 0805 |
| 限流电阻 | 1kΩ |
| LED 电流 | (5V - Vf_LED - V_OH) / 1kΩ ≈ (5 - 2.0 - 0.2) / 1k = **2.8mA** |
| 总功耗 | ~14mW |

> 状态指示建议：常亮 = 从机正常待命; 快闪 = 通信帧检测到错误; 灭 = 未上电或故障。

## 3. TLC555 电容传感电路

### 3.1 电路原理图

```
                              +5V (总线 VCC)
                               │
                          [R1 = 10kΩ]
                               │
                               ├─────── DIS (TLC555 pin7)
                               │
                          [R2 = 33kΩ]
                               │
                               ├─────── THRES (pin6) + TRIG (pin2)
                               │
                     ┌─────────┤
                     │         │
               [C_para       [探头]
                100pF]        PCB 叉指电极
                NP0/C0G       (绝缘层 + 防水漆)
                     │         │
                     ├─────────┤
                     │
                    GND

TLC555 其他引脚:
  pin1 (GND)  → GND
  pin3 (OUT)  → STC8 P5.4/T0
  pin4 (RESET)→ VCC (常使能)
  pin5 (CTRL) → 10nF → GND
  pin6 (THRES)→ 见上
  pin7 (DIS)  → 见上
  pin8 (VCC)  → +5V

  共地: TLC555 GND = 探头 GND = 总线 GND
```

### 3.2 设计原理

TLC555 非稳态振荡器，频率由 R1、R2 和总电容 C_total 决定：

$$f = \frac{1.44}{(R_1 + 2R_2) \cdot C_\text{total}}$$

$$C_\text{total} = C_\text{para} + C_\text{soil}$$

其中 $C_\text{soil}$ 取决于土壤含水量和 PCB 探头的电场分布。

| 参数 | 选择 | 理由 |
|------|:---:|------|
| **R1 = 10kΩ** | 充电电阻 | 与 R2 配合得到合适频率，功耗极低 |
| **R2 = 33kΩ** | 放电电阻 | 33k 使 $R_1+2R_2 = 76\text{k}\Omega$，配合 100pF 得 ~190kHz |
| **C_para = 100pF NP0** | 并联基准电容 | 干端频率 ~184kHz (TLC555/T0 安全范围); 湿/干差异 ~580 计数, 分辨率好 |

### 3.3 频率与计数估算

| 土壤状态 | $C_\text{soil}$ | $C_\text{total}$ | 频率 | 10ms 脉冲数 |
|------|:---:|:---:|------|:---:|
| 探头在空气中 | ~3pF | 103pF | **184 kHz** | 1840 |
| 干燥土壤 | ~15pF | 115pF | 165 kHz | 1650 |
| 中等湿度 | ~40pF | 140pF | 135 kHz | 1350 |
| 湿润土壤 | ~80pF | 180pF | 105 kHz | 1050 |
| 浸水 / 饱水 | ~200pF | 300pF | 63 kHz | 630 |

> 动态范围：1840 − 630 = **~1200 计数**，分辨率约 **每计数 0.15pF**。Timer0 16 位上限 65535 远高于 1840，无溢出风险。

### 3.4 为什么选择 TLC555（而非 NE555）

| 对比 | NE555 (双极型) | TLC555 (CMOS) |
|------|:---:|:---:|
| 供电电流 | \~3~5mA | **~170μA** |
| 输出摆幅 | 0.5V ~ VCC−1.5V | **轨到轨** |
| 输入偏置电流 | ~100nA | **~10pA** (对高阻探头无影响) |
| 最高频率 | ~500kHz | **>2MHz** |
| 价格差异 | — | +~¥0.3 |

> TLC555 的低输入偏置电流对高阻抗探头（PCB 叉指 ~pF 级）至关重要。NE555 的 ~100nA 偏置会干扰微量电容测量，误差不可接受。

### 3.5 功耗

| 元件 | 电流 | 说明 |
|------|:---:|------|
| TLC555 (静态 + 振荡) | ~200μA @ 184kHz | CMOS 极低功耗 |
| R1 + R2 分压 | 5V / (10k+33k) = 116μA | 微小 |
| **TLC555 电路小计** | **~320μA** | — |

## 4. PCB 叉指探头

### 4.1 原理

土壤含水量增加 → 介电常数 εr ↑ (干土 εr≈5, 湿土 εr≈30, 水 εr≈80) → 叉指间电容 ↑ → TLC555 频率 ↓。

两层绝缘层天然阻断 DC 电流通路，避免电化学腐蚀：

```
     ←────── 电场线穿过土壤 ──────→
  ┌──────────────────────────────────────┐
  │         防水漆 (~100μm)               │  ← 外加
  │       PCB 阻焊层 (~25μm)              │  ← 出厂
  │   ════ 铜 (叉指A) ═══    ════ 铜 (叉指B) ═══ │
  │           FR4 基板                    │
  └──────────────────────────────────────┘
                    ↓↓↓
  ┌──────────────────────────────────────┐
  │              土壤                     │
  └──────────────────────────────────────┘
```

### 4.2 推荐几何参数

| 参数 | 值 | 说明 |
|------|:---:|------|
| 指宽 | **0.5mm** | 标准 PCB 工艺轻松实现 |
| 间距 | **0.5mm** | 间距越小电容越大，但受限于 PCB 厂能力 |
| 指长 | **15mm** | 过长则基板电容主导，过短则对土壤灵敏度不足 |
| 指对数量 | **10~15 对** | 10 对时空气电容 ~3pF |
| 覆铜 | 顶层叉指 + 底层实铜（GND 屏蔽） | 底层屏蔽减少杂散耦合 |
| 板厚 | **1.6mm** (标准 FR4) | — |

### 4.3 防水处理

| 步骤 | 材料 | 说明 |
|:---:|------|------|
| 1 | — | 探头 PCB 区域不盖阻焊（或正常出厂阻焊均可） |
| 2 | 聚氨酯三防漆 / 丙烯酸三防漆 | 刷涂 2~3 层，每层自然干燥 |
| 3 | — | 总厚度 ~100μm，对电容影响极小 |

> 不推荐硅胶/热缩管等厚涂层——会显著降低探头对土壤的灵敏度。

### 4.4 探头与主控 PCB 的关系

两种方案可选：

| 方案 | 优点 | 缺点 |
|------|------|------|
| **A. 一体 PCB** | 单板，无连接器，可靠性高 | 探头区域需要用长排线连接到土壤位置 |
| **B. 分体 PCB** (探头小板 + 主控板) | 探头可灵活布置 | 需 2-pin 连接器 + 屏蔽线 |

> 推荐方案 A：TLC555 输入阻抗极高，长走线 (~10cm) 引入的寄生电容仅 ~1~2pF，可被 C_para(100pF) 吸收，不影响测量。

## 7. 决策日志

| # | 决策 | 理由 | 替代方案 |
|---|------|------|---------|
| 1 | MCU 选 STC8G1K17A SOP-8 | 8051 核, Timer0 硬件计数, INT0/INT1 双外部中断, 宽压 2.5~5.5V, SOP-8 小巧 | STM8S003 (需额外电平转换), ATtiny85 (无硬件 16-bit Timer0 外部计数) |
| 2 | 振荡器选 TLC555 (CMOS) | 输入偏置 ~10pA 不干扰 pF 级测量; 静态电流 ~170μA 远低于 NE555 | NE555 (双极型, 偏置 ~100nA 干扰测量不可接受) |
| 3 | PCB 叉指探头 + 绝缘层 + 防水漆 | 双层绝缘天然阻断 DC 电解腐蚀; 无需额外 C_block; PCB 自蚀刻成本低 | 不锈钢棒 (需 C_block + 仍需防腐蚀), 石墨棒 (机械脆弱) |
| 4 | C_para = 100pF NP0 | 频率 63~184kHz 在 TLC555 和 STC8 T0 安全范围; 温漂极小 (NP0) | 47pF (干端频率 ~266kHz 偏紧), 220pF (灵敏度差) |
| 5 | R1=10k, R2=33k | $f \approx 1.44/(76\text{k}\Omega \cdot C)$, 合适; 功耗低 | 更小电阻 (功耗增大, 频率偏差受输出驱动能力影响) |
| 6 | P5.5 驱动 LED (不省) | 调试/排查时直观; 仅 2.8mA, 16 台共 45mA 在 5V 总线预算内 | 省 LED (故障时无法快速定位从机) |
| 7 | P3.0/P3.1 不引出调试串口 | 使用 SOP-8 烧录夹烧录/调试, 无需额外焊盘 | 引出测试点 (增加 PCB 面积, 不需要) |
| 8 | 局部储能用已有 47μF 电解 | 已有库存; 47μF 对 ~5mA 负载储能充裕 | MLCC 10μF (需额外采购) |
| 9 | 探头 + 主控一体 PCB | 少连接器, 可靠性高; 长走线寄生电容 ~2pF 被 C_para 吸收 | 分体 PCB (需 2-pin 连接器 + 屏蔽线, 成本增加) |
